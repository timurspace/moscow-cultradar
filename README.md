# moscow-cultradar

Рабочий публичный прототип «Культрадара»: отборная московская афиша музыки, театра, оперы, балета и разговорных событий.

## Структура

- `index.html` — каркас интерфейса.
- `styles.css` — оформление.
- `app.js` — фильтры, личные статусы, заметки, экспорт/импорт, календарь.
- `events.json` — публичные данные событий; именно его предполагается регулярно обновлять.

## Приватность

Личные статусы (`Собираюсь`, `Куплено`, `Позже`, `Пропустить`, `С Тимофеем`) и поля `До события` / `Что осталось?` сохраняются только в `localStorage` браузера под ключом `afisha-private-v2`. Они не записываются в репозиторий и не отправляются на сервер.

Экспорт личных данных создаётся вручную в JSON; импорт позволяет перенести их в другой браузер/устройство.

## Календарь

Карточка умеет:

- скачать `.ics`;
- открыть предзаполненное событие в Google Calendar.

Сайт не получает доступа на чтение или запись календаря пользователя.
